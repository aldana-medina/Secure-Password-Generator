# Secure Password Generator

## Objective
The objective of this project is to build a lightweight, cryptographically secure password generator in Python. This tool demonstrates the difference between standard pseudo-random number generation and cryptographically strong randomness required for handling sensitive security credentials.

### Skills Learned
- Writing clean, efficient code using generator expressions combined with the .join() method to build strings dynamically.
- Swapping the standard random module for Python's secrets module to utilize a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG), preventing sequence prediction attacks.
- Configuring Visual Studio Code's native Source Control features for seamless Git synchronization and automated repository pushes.

### Tools Used
- Python's core logic, secrets, and string modules.
- Visual Studio Code's primary IDE.
- Git & GitHub's version control, automated sync commits, and portfolio hosting.
